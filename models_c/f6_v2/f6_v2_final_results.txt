F6 RENODE FINAL EVIDENCE — V2 HYBRID CAN IDS
=============================================
Date: 2026-09-08

1. Scope
--------
Purpose:
- Evaluate concurrent CAN RX interrupt handling, foreground IDS processing,
  periodic ECU-like control task execution, sustained CAN load, saturation,
  message-processing loss, and long-duration stability.
- This is Renode simulation evidence prior to physical MCU validation.

Execution path:
SocketCAN(vcan1)
 -> Renode SocketCANBridge
 -> CANHub
 -> STM32F4 CAN1 FIFO0
 -> NVIC RX interrupt
 -> software RX queue
 -> V2 streaming feature extraction
 -> frozen LightGBM + Mahalanobis Hybrid IDS

RX ISR only captures/enqueues frames.
Feature extraction and IDS inference execute in foreground.
A periodic 100 Hz synthetic ECU-like control task executes concurrently
and is prioritized over foreground IDS processing.

IMPORTANT LIMITATION:
Renode 1.16.1 is used as a functional/timing-accounting simulator here.
These results are NOT physical STM32F4 throughput, physical CAN-bus bitrate,
cycle-accurate WCET, or physical MCU validation.

9. F6 Conclusion
----------------
Within the tested Renode environment:

- CAN RX interrupt handling and software queue operation were validated.
- The final frozen V2 six-feature Hybrid IDS operated on the actual
  SocketCAN -> CAN1 -> IRQ -> queue data path.
- A concurrent 100 Hz synthetic ECU-like control task was maintained.
- The observed reproducible IDS-ON internal lossless/lossy transition
  was bounded between approximately 843.75 and 847.66 fps.
- 843.75 fps was internally lossless in 3/3 repeated runs.
- 847.65625 fps produced queue overflow in 3/3 repeated IDS-ON runs.
- A 60-minute 500 fps run produced 100% CAN1->IDS processing coverage,
  zero SW queue overflow, zero feature errors, and zero control
  deadline misses.
- IDS-OFF A/B testing at approximately 847.66 fps produced 100%
  CAN1->processing coverage and zero SW queue overflow, demonstrating
  that Hybrid IDS inference contributes to the simulated processing
  saturation boundary.
- No tested IDS-ON condition produced a deadline miss in the prioritized
  100 Hz synthetic control task.
