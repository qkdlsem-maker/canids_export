F5 INTERPRETATION
-----------------
The frozen V2 Python model was exported directly to deterministic C
without retraining, and tested Python/C decisions matched on the
10,000-sample parity set.

The canonical Cortex-M4 build occupies approximately 247.66 KiB of
Flash under the stated image-size convention and 636 B of static RAM.
A stack canary measured 196 B of inference stack high-water on all
five representative paths.

Renode provides reproducible functional execution-path evidence and
instruction-equivalent execution counts. It does not provide
cycle-accurate Cortex-M4 WCET, physical inference latency, or actual
MCU CPU-utilization proof.

FINAL PHYSICAL-MCU ITEMS
------------------------
Still requiring measurement on the physical Cortex-M4 target:
- actual hardware cycle count / WCET evidence
- actual inference latency
- actual CPU utilization
- complete system Peak RAM including ISR/drivers/runtime
- hardware behavior under concurrent ECU/CAN interrupt load

These simulator results must therefore be presented as reproducible
pre-hardware deployment evidence, not as substitutes for physical
MCU measurements.
